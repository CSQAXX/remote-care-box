## 2. 硬件真相：不是 ES8388

需求文档（`开发需求文档.md`）里写的音频 codec 是 **ES8388**，这是**错的**。
ES8388 是裸板 DNESP32S3 的方案，和 BOX3 这块带屏幕的成品板不是一回事。

### I2C 总线实测（I2C0，SDA=3 / SCL=2）

| 地址 | 器件 | 说明 |
| --- | --- | --- |
| `0x18` | **ES8311** | 播放 DAC（`ES8311_CODEC_DEFAULT_ADDR 0x30 >> 1`） |
| `0x40` | **ES7210** | 四通道麦克风 ADC（`0x80 >> 1`） |
| `0x21` | GC0308 | 摄像头（走 SCCB） |
| `0x59` | AW9523B | IO 扩展器 |
| `0x19` | 未确认 | reg0 读回 0x00，待查 |

> ⚠️ **如果按 ES8388 配引脚会直接花屏。** ES8388 用 GPIO46/9/10/14/3，
> 而摄像头数据线正好是 GPIO9/10/46 —— 直接撞车。

### 引脚（正点原子 BOX3 官方 board config）

```
MCLK = GPIO21    BCLK = GPIO38    WS = GPIO39
DIN  = GPIO41  (codec → MCU, 录音)
DOUT = GPIO40  (MCU → codec, 播放)
```

### 电源（AW9523B 控制，`camera_power_reset()` 里已使能）

```
XIO12  XIO_VBAT_EN     = 1   音频 VBAT
XIO13  XIO_VDDA_3V3_EN = 1   音频 3.3V
XIO5   XIO_PA_CTRL     = 1   功放使能
```

## 3. 软件方案

### 3.1 组件

`esp_codec_dev` v1.6.2，**本地 vendored** 到
`firmware/components/esp_codec_dev/`（纯本地组件，不参与组件管理器的依赖求解）。

理由：组件服务器 `components.espressif.com` 虽然可达，但每次构建去拉依赖
会让构建不可重现。vendored 版本可离线构建。

对应 sdkconfig：

```
CONFIG_CODEC_ES8311_SUPPORT=y
CONFIG_CODEC_ES7210_SUPPORT=y
CONFIG_CODEC_I2C_BACKWARD_COMPATIBLE=y   ← 关键，见下
```

`CONFIG_CODEC_I2C_BACKWARD_COMPATIBLE` 必须开：板子上 I2C0 已经用旧版
`driver/i2c.h` 装好了驱动（摄像头 SCCB + AW9523B 都在这条总线上）。
新版的 `i2c_master` 会和旧驱动抢同一个端口，运行时 `abort()`。

### 3.2 数据通路

```
录音: 麦克风 → ES7210 (ADC) --I2S--> GPIO41 (DIN)  --> ESP32-S3
播放: ESP32-S3 --I2S--> GPIO40 (DOUT) --> ES8311 (DAC) → 功放 → 喇叭
控制: I2C0 (SDA=3/SCL=2)，与摄像头 SCCB、AW9523B 共用
```

### 3.3 源文件

| 文件 | 作用 |
| --- | --- |
| `firmware/main/audio_board.c` | 音频子系统全部实现 |
| `firmware/main/audio_board.h` | 对外 API |
| `firmware/main/audio_board.c` 的 `audio_monitor_task` | 每秒报一次录音电平 |
| `firmware/main/audio_board.c` 的 `audio_tone_task` | 循环播 440Hz 测试音 |

## 4. 踩过的坑（两个，都已写进代码注释）

### 坑 1：ES8311 和 ES7210 的**打开顺序**不能反

**现象**：`i2s_channel_write` 返回 `ESP_ERR_TIMEOUT`（要 1024 字节只写了 256），
喇叭完全没声音。

**根因**：ESP32-S3 的 I2S 全双工时 RX 和 TX 共享时钟。单独改 RX 的时钟配置
在 TX 已使能的情况下不生效，`esp_codec_dev` 靠这段代码补：

```c
/* audio_codec_data_i2s.c, set_fs() */
if (skip == false && playback == false &&
    paired && paired->out_handle != NULL && paired->out_enable == false) {
    // TX 是 master, 只设 RX 不生效, 需要把 TX 也 reconfig 一遍
    _i2s_drv_enable(paired, true, false);
    set_drv_fs(paired->out_handle, true, ...);
    _i2s_drv_enable(paired, true, true);
}
```

注意那个 **`paired->out_enable == false`** 的前提 —— 这段同步逻辑
**只在 TX 还没打开时才会跑**。

| 打开顺序 | 结果 |
| --- | --- |
| 先 ES8311(播放) → 再 ES7210(录音) | ❌ RX 改时钟时 TX 已 enable，同步逻辑被跳过 → TX 的 DMA 配置和实际时钟对不上 → 写入超时 |
| **先 ES7210(录音) → 再 ES8311(播放)** | ✅ 正常 |

**代码里已经固定成先开 ES7210**，并留了详细注释。

### 坑 2：播放/录音必须按**真实速率**喂，不能一口气灌

**现象**：同上，超时。

**根因**：I2S TX 的 DMA 队列深度有限。一次性塞 1 秒的音频（16000 帧）
会塞满队列，之后 `i2s_channel_write` 拿不到新的 DMA buffer 只能干等 → 超时。

**修法**：
- 播放：每 256 帧（16 ms @16kHz）写一次，延时按实际写入帧数换算
- 录音：同理，读完按实际帧数延时，保持收支平衡

改完之后连续播放 1 分钟无超时。

## 5. 验证方法与证据

### 5.1 编译期 / 启动期

```
audio: ==== 音频初始化 (ES8311 + ES7210) ====
audio: I2S 通道就绪 (MCLK=21 WS=39 BCLK=38 DIN=41 DOUT=40, 16000Hz)
ES8311: Work in Slave mode
ES7210: Enable ES7210_INPUT_MIC1
ES7210: Enable ES7210_INPUT_MIC2
Adev_Codec: Open codec device OK     ← ES8311
Adev_Codec: Open codec device OK     ← ES7210
audio: 音频就绪: ES8311(0x30) 播放 + ES7210(0x80) 录音, 16000Hz
```

### 5.2 全双工验证（关键证据）

**方法**：板子循环播 440Hz 测试音，同时持续录音并统计电平。
喇叭的声音会被麦克风拾到（回授），因此**录音电平应该跟着"响/停"周期跳动**。

```
I (4468) audio: AUDIO: peak=2274 rms=1020 [有声音]
I (5468) audio: AUDIO: peak=111  rms=33  [静音]
I (6468) audio: AUDIO: peak=77   rms=27  [静音]
I (7468) audio: AUDIO: peak=2159 rms=1030 [有声音]
I (8468) audio: AUDIO: peak=121  rms=36  [静音]
I (9468) audio: AUDIO: peak=304  rms=101 [静音]
I (10468) audio: AUDIO: peak=2191 rms=1026 [有声音]
```

- 响时 rms ≈ 780–1030
- 停时 rms ≈ 21–36（只剩底噪）
- 周期 3 秒，与测试音配置（响 1 秒 + 停 2 秒）完全吻合

**这比"I2S 写入成功"有力得多** —— 写入成功只证明软件侧没问题，
回授证明**声音真的从喇叭出来了，并且麦克风真的拾到了**。

### 5.3 人工确认

用户实听确认：**喇叭有声音** ✅

### 5.4 对视频无影响

```
kanhu: PROD: 350 frames (24.1 fps) | get 29801us copy 5028us jpeg 0us | TORN 0/350
```

帧率 24 fps，花屏计数 0（音频和视频互不干扰）。

## 6. 串口命令

| 命令 | 作用 |
| --- | --- |
| `tone` | 开关循环测试音（toggle） |
| `astat` | 打印音频统计（peak / rms / 累计样本 / 是否有声） |
| `astop` | 停掉所有音频后台任务 |
| `stat` | 打印视频统计（帧数 / JPEG 字节 / TORN） |
| `lcd0` / `lcd1` / `lcd2` | 切 LCD 显示模式（摄像头 / 测试图样 / 合成渐变） |

> ⚠️ `uart_cmd_task` 用 `read(STDIN_FILENO)`，和 IDF console 抢 stdin，
> 串口命令在某些情况下不生效。后续应改用 `esp_console_cmd_register`。
> 临时绕过方式：把 `AUDIO_SELFTONE` 改成 1 重新烧录（开机自动播测试音）。

```c
/* main.c */
#define AUDIO_SELFTONE      0   /* 1 = 开机自动循环播 440Hz 测试音 */
```
